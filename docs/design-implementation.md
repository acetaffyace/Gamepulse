# 游戏长线运营情报看板：单图桌面版设计与实现文档

**版本：** 0.2  
**适用范围：** 游戏长线运营情报看板 MVP  
**默认示例：** 《绝区零》  
**硬约束：** 浅色主题、仅桌面端、一个综合图展现全部核心信息。

---

## 1. 设计结论

MVP 只做一个桌面端页面，不做传统的多卡片、多图表后台。

页面结构：

    顶部上下文与筛选
              ↓
    一张 Operations Pulse 综合图
              ↓
    图例、数据状态、口径和来源

综合图使用同一日期轴的六个水平轨道。视觉上只有一个图表容器，语义上每个轨道保留自己的单位和刻度：

1. Steam 同时在线人数；
2. Steam 好评率；
3. Steam 新增评测数（讨论热度代理）；
4. 价格和折扣；
5. 版本、角色、活动和维护事件；
6. B 站角色视频播放量/增量。

不把在线人数、百分比和播放量硬塞到同一个 Y 轴，也不通过一个“综合热度分数”替代原始指标。

## 2. 参考风格

### 2.1 可借鉴

- SteamDB：信息密度、历史时间线、工具感；
- Linear：浅色工作台、细边框、清晰状态；
- Vercel：留白、克制、低装饰；
- Observable/Datawrapper：图表优先、注释清晰；
- Black Myth Game Ops Dashboard：版本/事件与趋势联动。

### 2.2 不复制

只参考信息架构和交互原则，不复制代码、Logo、角色立绘、品牌色或页面截图。

### 2.3 视觉气质

- 白底或浅灰画布；
- 深灰文字、细灰边框；
- 低饱和蓝/青/紫/琥珀色；
- 无深色模式；
- 无霓虹、渐变大背景、发光卡片、3D 图表和装饰性大图；
- 像一份专业的游戏运营研究工作台。

## 4. 浅色设计 Token

所有颜色集中定义，组件不自行散落颜色值。

| Token | 色值 | 用途 |
|---|---|---|
| canvas | #F7F8FA | 页面背景 |
| surface | #FFFFFF | 图表容器 |
| surface-subtle | #F1F3F5 | 轨道背景/hover |
| border | #DDE2E8 | 边框/分隔线 |
| text-primary | #1F2937 | 主文字 |
| text-secondary | #596579 | 次要文字 |
| text-muted | #8A95A5 | 时间/来源/限制 |
| accent-blue | #2563EB | 在线人数 |
| accent-teal | #0F9F91 | 好评率 |
| accent-purple | #7C3AED | 新增评测/角色事件 |
| accent-amber | #C77B10 | 折扣/待关注 |
| accent-red | #C2414B | 维护/异常/过期 |
| accent-green | #18864B | 正常状态 |

颜色必须同时配合文字、图标、线型或轨道位置，不能只依靠颜色传达含义。

字体：

- 中文优先使用 Microsoft YaHei、PingFang SC 或 Noto Sans CJK SC；
- 英文/数字使用 Inter 或系统 sans-serif；
- 数字使用 tabular-nums；
- 标题 20–24px；
- 轨道标题 12–13px；
- 正文 13–14px；
- 来源说明 11–12px。

## 5. 综合图设计

### 5.1 组成

综合图名：Operations Pulse。

| 轨道 | 数据 | 图形 | 颜色 |
|---|---|---|---|
| L1 | Steam 同时在线 | 折线 + 可选 7 日均线 | 蓝 |
| L2 | Steam 好评率 | 折线 | 青 |
| L3 | Steam 新增评测 | 柱状图 | 紫 |
| L4 | 价格/折扣 | 阶梯线 + 折扣底带 | 琥珀 |
| L5 | 版本/角色/活动 | 事件针、标签、区间 | 多色语义 |
| L6 | B站角色视频 | 视频点位 + 日增棒 | 紫/青 |

所有轨道共享同一 X 轴、时间范围、缩放和 hover 十字线。

### 5.2 L1 在线人数

- 数据：Steam current players；
- 单位：Steam 同时在线人数；
- 原始线 2px；
- 可选 7 日移动平均虚线；
- 缺失天数保持断点；
- tooltip 显示采集时刻、平台和质量状态；
- 文案禁止使用 DAU、活跃用户或总玩家数。

### 5.3 L2 好评率

- 默认累计全部评价好评率；
- 若有近期评价，图例切换累计/近期；
- 单位：百分比；
- 轨道旁显示“累计指标，变化较慢”；
- 评测总量不与好评率共用刻度；
- 不自动写“口碑变好/变坏”。

### 5.4 L3 新增评测

- 公式：当日总评测数 - 上一条有效快照总评测数；
- 标题必须含“讨论热度代理”；
- 第一条快照显示“等待下一条快照”；
- 负差值使用灰色异常点，不绘制负柱；
- tooltip 展示前值、当前值、计算公式和异常原因。

### 5.5 L4 价格/折扣

- 当前价格优先来自 Steam Store；
- 历史价格可用 SteamDB 或人工 backfill；
- 价格用阶梯线；
- 折扣用浅琥珀色背景带；
- 付费游戏显示原价、折后价和折扣比例；
- 免费游戏显示“免费”，不绘制无变化的本体折扣线；
- DLC/礼包必须单独建商品序列；
- SteamDB 数据显示 third-party 标签。

### 5.6 L5 事件轨道

事件类型：

- patch：蓝色竖线；
- character_release：紫色竖线；
- character_demo：紫色圆点；
- season/event：青色区间；
- sale：琥珀色区间；
- maintenance：红色三角；
- official_news：灰色小点。

规则：

- 同一天多个事件合并；
- 超过 3 个标签显示 +N；
- 点击事件打开右侧来源抽屉；
- 事件只代表时间节点，不代表因果；
- 角色事件与对应 B 站视频共享日期垂线。

### 5.7 L6 B 站角色视频

视频按以下层级组织：

    游戏 → 版本 → 角色 → 视频类型 → 播放量快照

默认显示：

- 官方角色 PV；
- 官方角色试玩/战斗演示；
- 官方角色 EP（如果有）。

可选显示：

- 媒体视频；
- 创作者攻略/解析；
- 版本前瞻。

图形：

- 点的位置：视频发布时间；
- 点大小：播放量对数缩放；
- 点颜色：官方/媒体/创作者/攻略；
- 点下方：近 7 日播放增量；
- 同一角色多个视频垂直堆叠；
- 默认只显示官方视频，避免单个创作者爆款扭曲整体趋势。

tooltip 必须包含：角色、版本、视频类型、标题、UP 主、当前播放量、近 7 日增量、BV 号、发布时间、来源 URL、抓取时间。

## 6. 交互规则

### 6.1 Hover 联动

鼠标移动到任一轨道：

- 显示贯穿六个轨道的竖向十字线；
- tooltip 按轨道分组显示当天数据；
- 显示日期、单位、数据性质、来源和质量状态；
- 缺失字段显示暂无数据；
- 同日事件和视频点位一并显示。

### 6.2 点击与来源抽屉

点击任意事件、数据点或视频：

- 右侧打开来源抽屉；
- 显示原始值、计算公式、来源 URL、抓取时间；
- 显示 observed/derived/proxy/manual/unavailable；
- 显示 Steam/SteamDB/B站覆盖限制；
- 抽屉不是第二页面，也不渲染第二张图。

### 6.3 图例开关

支持开关：

- 在线原始值；
- 在线 7 日平均；
- 累计/近期好评率；
- 官方/媒体/创作者视频；
- 版本/角色/折扣事件。

关闭轨道后保留轨道标题和空状态，避免布局跳动。

### 6.4 对比模式

最多选择两款游戏：

- 在线使用首日=100 指数化；
- 好评率保持绝对百分比；
- 事件分行；
- 不同货币不合并价格轴；
- B站按各自登记视频集合显示；
- 仍然只使用一个综合图。

## 8. 质量与异常状态

必须检查：

- 主键和逻辑唯一键；
- 在线、评测、价格、播放量为非负数；
- 好评率 0–100%；
- 折扣 0–100；
- 时间戳不晚于当前；
- BVID 有效且不重复；
- 评测数/播放量倒退；
- 48 小时内是否有有效快照；
- 每个展示值能回链到来源。

状态：

| 状态 | 行为 |
|---|---|
| ok | 正常绘制 |
| partial | 绘制可用轨道并提示缺失 |
| stale | 绘制最近值并提示过期 |
| invalid | 不进入趋势计算 |
| unavailable | 显示暂无数据 |

## 9. 视觉 QA

基准验收尺寸：

- 1440 × 900；
- 1280 × 800；
- 低于 1200px 只验证横向滚动提示；
- 不验收移动端。

必须测试：

- 仅有 3 天快照；
- Steam Store 返回 success=false；
- SteamDB 403/限流；
- B站视频删除；
- 评测数或播放量倒退；
- 同一天多个角色和版本事件；
- 长角色名、长视频标题；
- 免费游戏价格轨道；
- 付费游戏折扣区间；
- 事件密集的一周；
- 轨道全部关闭/重新打开。

验收要点：

- 页面只有一个主要图表容器；
- 六个轨道共享日期轴；
- 浅色主题且对比度足够；
- 缺失数据有断点/暂无数据；
- tooltip 和来源抽屉不被裁切；
- 事件标记不遮挡全部趋势；
- 图表切换小于 300ms；
- 不在浏览器端加载 raw 评论或完整历史文件。
