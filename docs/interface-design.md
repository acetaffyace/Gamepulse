# GamePulse 界面规范

[项目首页](../README.md) · [指标与技术说明](technical-notes.md)

## 信息与布局

界面采用浅色留白和黄、青、粉模块色。首屏先给范围、数字和图形，具体口径与样本按需展开。指标卡固定两行：短标签与可选趋势在第一行，主数字与简短单位在第二行。卡片内不放说明段落。

总览使用评测数、好评率、日均在线三个主指标；日均评测、时长中位数、有效样本与对照日期在“覆盖”中查看。覆盖不足用短状态提示并提供来源入口，已有观测继续显示，缺失不补零。趋势里的“点”指百分点，仅在有效覆盖一致时给出变化。

双版本卡片展示 B 的值，趋势比较 A；A/B 原值通过“对照”查看。分析方式保留双版本、多版本、更新前后、版本节奏。多版本汇总和前后对照使用表格，图与导出共用原有指标计算。

图表用短标题、图例、单位和对象颜色传达含义。“口径”保留样本、覆盖、纵轴缩放与解释边界，PNG 与 JSON 导出保留完整上下文。数字、表格与编辑区域保留必要单位、数据和操作反馈，名称优先使用 2～6 字的业务短标签。

桌面使用两列图表，1120px 以下为单列；1024px 以下导航移到顶部；520px 以下采用六项紧凑导航、三列主指标、单列图表。手机查询默认先呈现结果，展开后连续修改条件保持面板打开。

## 颜色与组件

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面 | `#ffffff` | `#181c19` |
| 表面 | `#ffffff` | `#1b211d` |
| 正文 | `#20231f` | `#f3f5ef` |
| 次要文字 | `#535b52` | `#c3ccc0` |
| 黄色模块 | `#fff09a` | `#3a3523` |
| 青色模块 | `#b4efe6` | `#223e37` |
| 粉色模块 | `#ffd5e0` | `#422e37` |

模块色用于内容分组。游戏、语区等图形对象仍由 `web/lib/palette.js` 按固定身份取色，来源状态同时用状态点和文字表达。

| 项目 | 规范 |
|---|---|
| 字体 | 本机系统无衬线字体，数字使用等宽数码 |
| 字号 | 正文 14px，辅助 12/13px，标题 32px；手机标题 28px |
| 间距 | 4、8、12、16、24、32px；图表组间距 24px |
| 圆角 | 控件 8px，卡片 16px |
| 指标数字 | 桌面 38px；手机按宽度在 20～22px 间调整 |
| 操作尺寸 | 常规控件 36px；手机图表菜单、图例、分页与恢复操作至少 44px |
| 阴影 | 用于弹出菜单；内容卡以边界和留白分组 |
| 状态 | hover、focus、pressed、disabled；键盘焦点轮廓 2px |
| 动效 | 160ms 色彩过渡；尊重减少动态效果设置，图表不添加额外数值动画 |

样式变量维护在 `web/app.css`。SVG 图标统一线宽、端点和视口；品牌标记桌面 36px、手机 30px，导航图标 19/16px。`web/favicon.svg` 用于浏览器页签，`web/brand-mono.svg` 为单色标记；单色文件使用 `currentColor`，可内联或作为蒙版使用。

## 状态与交互

最新一次导航决定页面提交，网址、导航高亮、标题和导出对应同一页。模块导入失败显示该页错误与重试入口；重试会重新请求模块。引擎、数据库与页面错误都有恢复操作，诊断详情按需展开。

查询条件存在网址里。单游戏上下文跨页继承，日期与阶段保留各页各自的选择，避免把日历窗口当成更新阶段。没有明确游戏范围时沿用目标页已有选择。展开状态、图例、图表/表格切换、搜索排序页码与焦点保存在标签页内。

SQL 草稿、已执行语句与最后结果分别保存。主题切换和页内导航不执行草稿；运行时提供“查询中”反馈。失败保留上次成功结果并标注。链接中的 SQL 仍需手动运行，数据库只读，返回上限 5000 行。

空状态使用短提示和对应操作，例如“样本不足”“暂无观测”，再提供查看来源、扩大日期或清除筛选的入口。弹出菜单可按 Escape 关闭，定位限制在视口内；页面提供跳到内容入口和状态播报。

## 加载与验证

数据下载、查询引擎与所需图表引擎并行加载。来源页和 SQL 模式不加载 ECharts；首次进入图形页再加载。数据库解压、SQL 初始化、计算与图表绘制仍需要时间，运行耗时查询的主线程隔离属于后续根据实测选择的优化。
数据载入期间可以先选择页面；载入完成后提交所选页。图表引擎失败不阻止进入无需图形的来源页或 SQL 模式。

检查包含合成数据的独立 SQL 对照、读写限制与导出，真实公开数据副本的三引擎截图、手机/平板/宽屏与深浅色检查，以及限速、CPU 降速和缓存条件下的加载测量。浏览器引擎检查不等同于真机或屏幕阅读器实测；性能数据注明环境与采样次数。
