# 永劫无间数据接入

永劫无间是 `naraka_bladepoint`，作为游戏进入与鸣潮、绝区零相同的六个页面。
没有独立游戏页、独立任务或自动面试简报。原有前端与其它游戏登记范围保留。

## 查看与更新

本机运行 `scripts\serve.cmd`，在页面游戏选择器中选“永劫无间”：

- 运营总览：统一窗口的评测、好评率、视频；SteamDB 日均为空时展示独立的自然月参考。
- 版本对比：已确认补丁之间的 D0 对比、更新前后与节奏；多对象模式可以与鸣潮、绝区零比较。
- 视频传播：B 站与 YouTube 默认可见，按语区、类型、版本筛选，同龄曲线与跨平台内容对照。
- 玩家结构：各补丁窗口的评测语种、时长分布、分组好评与成熟评测者后续游玩。
- 自助查询和数据来源：与其它游戏使用同一套指标、原始记录、覆盖与导出。

```powershell
python collect.py --game naraka_bladepoint
# 有界回填评测；2026-10-08 的近三月再向前补到首个补丁完整起点：
python collect.py --game naraka_bladepoint --only reviews --since 2026-07-02
# 官网公告回溯（仍在现有数据来源页查看）：
python collect.py --game naraka_bladepoint --only official_news --since 2026-07-08
```

每天的已登记视频更新使用原 B 站/YouTube 采集器和 `.env` 配置。没有新增 Key 或登录要求。
以上命令生成本机 `dist/`，不推送远程，也不更改计划任务。现有任务实际路径仍需核实。

## 覆盖边界

有界回填记录在 `review_window_run`，完整到达起点后才写入；异常缩减或翻页失败保留旧事实。
只有覆盖完整的日期才能补 0，当前采集日排除，分离窗口间的缺口不补。数据是当前仍存续评测，
不是历史精确新增。玩家语言不代表所在地区，Steam 数据不能当作国服 DAU 或真实留存。

视频计数是开始采集后的观测，不从累计值伪造过去逐日播放。当前同龄比较会显示已观测点与缺口。

SteamDB 日均使用 Charts CSV 导入，Windows 可用已登录 Edge 的 `tools.steamdb_edge_export` 自动导出；
2026-10-08 已更新四款至 10-07。SteamCharts 只存已结束自然月的平均/峰值，
没有日均的游戏可在原总览看到“自然月在线参考”；月度值不进入 D0、更新前后或日均比较卡。
其公开图形接口混有月峰、日峰与近期时点，不能全部当成日平均写入 `online_daily`。

Steam 构建号镜像对本 App 返回 `_missing_token` 且没有 public branch，当前记为采集失败，
不绕过权限、不编造构建号。补丁日期以官方更新公告为依据，不依赖构建号生成窗口。

真实替换前使用 SQLite backup API 保存 `data/backups/before-shared-integration-*.sqlite`。
恢复时先停采集，保留当前库，再通过 SQLite backup API 写回选定备份，避免覆盖正在使用的 WAL 库。
`data/`、`dist/`、原始响应和 `.env` 不进入代码分支。
