# GamePulse Studio 工作台

从仓库根目录启动 `python -m http.server 8771`，打开：

- 总览：`http://127.0.0.1:8771/dashboard/index.html?page=overview`
- 版本对比：`http://127.0.0.1:8771/dashboard/index.html?page=versions`
- 视频传播：`http://127.0.0.1:8771/dashboard/index.html?page=videos`

工作台复用采集流水线的快照、对比引擎、指标配置、视频口径、CSV 和 PNG 导出。使用独立的浏览器存储键，不覆盖原版的视图设置。所有资源本地加载。

## 第二轮布局

- 版本页提供 A/B 选择、交换、统一起点窗口、四组指标卡、评测量/好评率/在线切换，以及单图 PNG。完整轨道与明细表按需展开。差值使用中性配色，不将数量增减自动解释为好坏。
- 累计视频默认使用横向排行，支持切回发布时间散点图。平台、语区、内容类型、指标、刻度、分面/叠图、同内容联动和导出入口继续可用。
- 排行保留采样日期和视频年龄，追踪增量、发布同龄、每日净增继续使用原有时间序列与缺采规则。
- 首页与视频页使用相同的视频取数和最近有效采样规则。分享链接保存页面、排行/时间图选择及原有筛选条件。

## 验证

`npm run test:studio`：独立从原始评测历史核对 3/7/14 天对比总量，检查 A/B 交换、图表切换、真实横条点击联动、平台公式约束、缺采空态、CSV/PNG、分享恢复与 390px 手机布局。

`npm test`、`npm run test:browser`：原有口径测试与原版看板交互回归。

此布局已成为正式入口 `dashboard/index.html`。旧演示链接自动跳转；经典视图保留在 `dashboard/legacy.html`。生产改造与测试结果见 [验收记录](production-upgrade-2026-09-29.md)。
